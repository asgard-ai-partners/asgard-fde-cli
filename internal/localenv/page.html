Design-time credentials

These are the values the coding agent uses on this machine to read the systems being modelled. They are written to a file that is never committed.

This is not the same thing as a pipeline variable or a runtime secret in the cluster - the value may be identical, but each is set in its own place. Nothing typed here leaves this computer, and nothing typed here is printed back to the agent: it is told which keys were filled in, never what they were filled in with.

If you know about something the agent did not ask for - a second database, another account - add it here. The agent re-reads the file after you save, so it will see it.
